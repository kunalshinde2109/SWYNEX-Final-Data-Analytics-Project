# SWYNEX Final Data Analytics Project
## Titanic Survival Analysis

### Project Overview
This project presents a complete Data Analytics Case Study based on the Titanic passenger dataset. It combines data cleaning, exploratory data analysis (EDA), and an interactive Power BI dashboard to understand passenger survival patterns.

### Problem Statement
The objective of this project is to analyze Titanic passenger data and identify the factors associated with passenger survival, including gender, passenger class, age group, and fare.

### Dataset Information
- Dataset: Titanic Passenger Dataset
- Total Records: 891
- Total Columns: 15
- Format: CSV

### Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook
- Power BI
- DAX
- Git and GitHub

### Project Workflow

#### 1. Data Cleaning & Preparation
- Inspected the raw dataset.
- Identified missing values.
- Handled missing values using suitable statistical methods such as median and mode.
- Checked data types and duplicate records.
- Exported the cleaned dataset.

#### 2. Exploratory Data Analysis (EDA)
- Analyzed passenger survival distribution.
- Studied survival by gender and passenger class.
- Explored age-group survival patterns.
- Examined passenger fare distribution.
- Identified important patterns and insights.

#### 3. Interactive Power BI Dashboard
The dashboard includes:
- Total Passengers KPI
- Overall Survival Rate KPI
- Average Age and Average Fare KPIs
- Gender-wise Survival Analysis
- Class-wise Survival Analysis
- Age Group-wise Survival Analysis
- Passenger Fare Distribution
- Passenger Survival Distribution
- Interactive slicers and filters

### Key Insights
- Total passengers analyzed: 891.
- Overall survival rate: 38.38%.
- Female survival rate: 74.20%.
- Male survival rate: 18.89%.
- First-class survival rate: 62.96%.
- Child survival rate: 57.97%.
